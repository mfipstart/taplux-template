# Добро пожаловать в Taplux! 🚀

Вы успешно создали свое хранилище для сайтов на базе нашего шаблона.

Вам **не нужно** редактировать файлы вручную, писать код или создавать папки. Вся работа по созданию сайтов, добавлению новых проектов (multi-site) и настройке доменов происходит в удобной панели управления.

## Что делать дальше?

1. Перейдите в панель управления: **[admin.taplux.ru](https://admin.taplux.ru)**
2. Введите ваш лицензионный ключ (пришел на почту после оплаты).
3. Авторизуйтесь через GitHub (кнопка в админке).
4. Нажмите «Новый сайт» и начните творить!

Система сама создаст нужные папки, автоматически сгенерирует структуру в хранилище и опубликует ваш сайт в интернете (на Vercel). 

---

### ⚠️ Важно о приватности
Мы настоятельно рекомендуем в настройках этого репозитория на GitHub (вкладка **Settings** -> General -> прокрутить вниз до Danger Zone -> **Change visibility**) убедиться, что репозиторий имеет статус **Private** (Приватный). Если он Public — измените на Private. Это скроет все ваши данные и черновики сайтов от посторонних глаз. Наша система полностью поддерживает работу с приватными хранилищами.

---
*Служебная информация: файлы `index.html`, `js/core-loader.js` и `vercel.json` в этом репозитории трогать не нужно. Они служат лишь загрузчиком и автоматически подтягивают актуальное ядро Taplux с наших защищенных серверов.*
